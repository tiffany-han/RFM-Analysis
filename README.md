# RFM-Analysis
2026/10/7 CDRI AI協作數據分析 exercise
## Introduction
本專案旨在針對 **2018/01/01 至 2019/01/04** 期間的銷售數據進行 **RFM 客群價值分析**，並透過機器學習演算法（K-Means）將客戶進行科學分群，以便針對不同的客群制定客製化的行銷與營運策略。
### 📊 分析指標說明
在分析中，我們從銷售資料表中提取了以下三個關鍵指標（RFM）：
* **R (Recency) 近期消費**：客戶距離最後一次消費過了幾天。天數越少代表近期越活躍。
* **F (Frequency) 消費頻率**：客戶在分析期間內的總消費次數。次數越多代表黏著度越高。
* **M (Monetary) 消費金額**：客戶的總消費金額。金額越高代表貢獻度越大。

### 🔄 分析與建模步驟
1. **資料導入與整理**：讀取銷售原始資料，確保日期欄位格式正確。
2. **指標計算**：以資料集中的最大日期（2019/01/04）作為基準日，計算每位客戶的 R、F、M 數值。
3. **特徵標準化**：由於 R、F、M 的單位與數值範圍差異較大，分群前使用 `StandardScaler` 進行標準化，確保分群結果不受極端值影響。
4. **K-Means 演算法分群**：將客戶分為 **4 個群體**，並透過成對散布圖（Pairplot）進行視覺化呈現。

### 👥 客群分群結果摘要
根據模型結果，我們將客戶細分為以下四類：

| 群體編號 | 客群定位 | 客群特徵 (R / F / M 平均值) | 建議行銷策略 |

| **群體 0** | **🌟 潛力主力客群** | 剛消費過 (R ≈ 18天)、頻率高 (F ≈ 19次)、消費金額中等 (M ≈ 4.5萬) | 透過交叉銷售（Cross-selling）或滿額禮，提升單筆消費金額。 |

| **群體 1** | **💤 輕度/新進客群** | 中期未消費 (R ≈ 45天)、頻率低 (F ≈ 5.6次)、消費金額少 (M ≈ 1.3萬) | 發送限時折扣或問卷，喚醒購買欲並引導回購。 |

| **群體 2** | **👑 VIP 核心客群** | 剛消費過 (R ≈ 15天)、頻率最高 (F ≈ 26次)、消費金額極高 (M ≈ 7.6萬) | 提供專屬 VIP 福利與新品搶先體驗，維持高黏著度。 |

| **群體 3** | **🍂 沉睡/流失客群** | 極久未消費 (R ≈ 183天)、頻率極低 (F ≈ 3.6次)、金額極少 (M ≈ 0.8萬) | 採低成本的自動化再行銷（如節慶 E-mail 關懷），不建議過度投資。 |
